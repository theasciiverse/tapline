# Bellbeat songs

Eight songs from Bellbeat, the Asciiverse's own rhythm game, every one
written for it and played here by its own synth: Hello, World; Segfault
March; Waltz for a Spinning Disk; Carriage Return; Escape Sequence;
Kernel Panic; Null Pointer Samba; SIGTERM.

Each is a keysound chart: the band plays the backing, and every note you
hit is that very note of the melody, so a miss leaves a hole in the tune.
The 4-key chart (S D K L) gives you the notes on the beat and plays the
rest itself; the 7-key chart (S D F Space J K L) is the whole melody.

Music by Asciiverse (https://asciiverse.sh), MIT, from
https://github.com/theasciiverse/bellbeat. Made with
asciiverse/bellbeat-charts.sh in theasciiverse/tapline.
